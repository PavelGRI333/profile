Персональный сайт-портфолио с формой обратной связи и админ-панелью для управления сообщениями. Поддерживает два языка (русский/английский) и полностью адаптирован под мобильные устройства.

**Ключевые возможности:**
- 🐍 Бэкенд на FastAPI с автоматической документацией Swagger
- 📬 Форма обратной связи с hCaptcha-защитой
- 🔐 Админ-панель для просмотра и управления сообщениями
- 🌐 Двуязычный интерфейс (RU/EN) с сохранением выбора
- 📱 Адаптивный дизайн для всех устройств
- 🐳 Полная контейнеризация через Docker Compose
- 🔒 HTTPS через Let's Encrypt

## 🛠 Технологический стек

| **Категория** | **Технологии** |
|---------------|----------------|
| 🐍 Бэкенд | FastAPI, Uvicorn, Python 3.12 |
| 🗄 База данных | PostgreSQL 16, SQLAlchemy (async), Alembic |
| ✅ Валидация | Pydantic, Pydantic Settings |
| 🎨 Фронтенд | HTML5, CSS3, JavaScript, Slick.js, jQuery |
| 🔒 Безопасность | hCaptcha, CORS, JWT, HTTPS (Let's Encrypt) |
| 🐳 Деплой | Docker, Docker Compose, Nginx, Certbot |
| 📦 Зависимости | Poetry |

| **Git** | 2.0+ | `git --version` |

### 📦 Установка и запуск
```bash
#### 1️ Клонируйте репозиторий
git clone https://github.com/PavelGRI333/profile.git
#### 2 Клонируйте репозиторий
Cоздайте .env и заполните данные по шаблоне .env.template
#### 3 Запустите контейнеры
docker compose up -d --build
#### 4 Примените миграции базы данных
```

| | Сервис | Адрес |
